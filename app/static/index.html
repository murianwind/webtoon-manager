아카이빙 기능 사용 안내

아카이빙은 다운로드 폴더에 쌓인 웹툰을 별도 보관 위치로 자동 정리하는 기능입니다. 아직 보관 위치가 설정되어 있지 않아서, 아래 둘 중 하나를 설정하셔야 이 탭을 쓰실 수 있습니다.

1. 로컬 폴더 사용 — docker-compose 환경변수에 ARCHIVE_ROOT(컨테이너 경로)와 WEBTOON_ARCHIVE_HOST_PATH(실제 보관할 Windows 폴더)를 추가하고 재배포하세요.

2. rclone 원격(원드라이브 등) 사용 — rclone config로 원격 연결을 설정한 뒤, 그 결과로 생긴 rclone.conf 파일이 있는 폴더를 RCLONE_CONFIG_HOST_PATH로 지정하고 재배포하세요.

자세한 설정 방법은 저장소 README의 "아카이빙 자세히" 항목을 참고하세요.

아카이빙 대상 웹툰

지정한 웹툰은 정해진 주기마다(마지막 회차는 남기고) 아래 그릇 폴더로 옮겨집니다. 여러 웹툰이 같은 그릇 폴더를 고르면 자동으로 웹툰별 폴더로 나뉘고, 하나만 쓰면 그릇 폴더 바로 밑에 쌓입니다.

완결 자동이동 설정

구독해제하는 즉시가 아니라, 아래 "실행 스케줄"이 돌 때 함께 처리됩니다. 지정 안 된 웹툰이 이 조건으로 트리거되면 "기본 그릇 폴더"를 씁니다 (지정된 웹툰은 자기 폴더로).
