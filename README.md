# 웹툰 구독 관리

네이버웹툰과 카카오페이지 웹툰을 자동으로 챙겨서 받아 주는 프로그램입니다.
**좋아하는 작가나 태그를 한 번만 등록해 두면, 그 뒤로는 신경 쓰지 않아도 새 작품을 구독하고 새 회차를 받아 줍니다.**
서버 콘솔이나 명령어 없이, 웹 브라우저 하나로 모든 것을 관리합니다.

## 이런 프로그램입니다

이런 분께 맞습니다.

- 좋아하는 작가가 새 작품을 냈는지 매번 확인하기 귀찮은 분
- 웹툰이 완결됐는지, 구독을 계속 유지할지 매번 고민하기 귀찮은 분
- 회차가 며칠~몇 주씩 밀려도, 한꺼번에 몰아 받다가 문제가 생길까 걱정되는 분
- 다운로드 폴더에 파일이 계속 쌓이는 게 신경 쓰이는 분(완결작을 별도 폴더로 자동 정리)

**자동으로 해 주는 일**

- **새 회차 자동 다운로드** — 정해 둔 시각마다 구독 중인 웹툰의 새 회차를 확인해서 받습니다(네이버, 카카오페이지). 이미 받은 회차는 다시 받지 않습니다.
- **신작 자동 구독** — 등록해 둔 작가(네이버는 태그도)의 새 작품이 나오면 알아서 구독하고 디스코드로 알려 줍니다.
- **다운로드 리포트** — 원하는 시각에 그동안 받은 작품과 실패한 작품을 모아 디스코드로 보냅니다.
- **완결 알림** — 구독 중인 작품이 완결되면 알려 주고, 그 자리에서 버튼으로 구독해제할 수 있습니다.
- **쿠키 만료 알림** — 네이버 성인 인증이나 카카오페이지 로그인이 풀리면 알려 줍니다.
- **정보 파일 자동 생성** — 웹툰 뷰어(Komga 등)가 읽을 수 있는 작품 정보와 표지를 폴더마다 만들어 줍니다.
- **아카이빙** — 오래된 회차와 완결작을 별도 보관 폴더로 자동 정리합니다.

## 핵심 개념 — 웹툰을 세 곳으로 나눠서 관리합니다

- **웹툰 전체목록**: **지금 구독 중인 웹툰**과, **구독은 안 하지만 계속 지켜보고 싶은 웹툰**이 모이는 곳입니다. 작품마다 플랫폼 배지("네이버"/"카카오")와 "구독", "목록제외" 버튼이 있습니다.
- **구독해제**: **예전엔 구독해서 받았지만, 지금은 자동으로 받고 싶지 않은 웹툰**입니다.
- **제외됨**: **아예 관심 없다고 정한 웹툰**입니다.

"구독해제"나 "제외됨"에 있는 웹툰은 두 가지로 되돌릴 수 있습니다.

- **"구독"**: 지금부터 다시 자동으로 받기 시작합니다.
- **"목록으로"**: 다운로드는 안 받지만, 전체목록에서 계속 찾아볼 수 있게 돌려놓습니다.

참고할 점이 몇 가지 있습니다.

- "구독해제" 탭에는 **실제로 한 번이라도 구독했던 웹툰**만 남습니다. 구독한 적 없이 "제외됨 → 목록으로"만 거친 웹툰은 섞이지 않습니다.
- 한 번이라도 구독한 웹툰은 "목록으로"를 여러 번 오가도 기록이 남아서, 플랫폼의 요일별 목록에 없는 완결·장기휴재 작품이어도 전체목록에서 다시 찾을 수 있습니다.
- 반대로 구독한 적 없는 웹툰을 "목록으로" 보내면, 플랫폼의 요일별 목록에 이미 없는 작품(완결·장기휴재)은 전체목록에서도 안 보일 수 있습니다. 플랫폼 쪽 목록 자체의 한계라서 이 프로그램이 되돌릴 수 없습니다.
- 카카오페이지는 요일 연재 중인 웹툰만 목록에 나옵니다. 완결작은 [카카오페이지 사용하기](#카카오페이지-사용하기)의 방법으로 구독합니다.

## 설치하기 (Docker / Portainer 기준)

미리 만들어진 이미지를 받아서 바로 실행합니다. 코드를 직접 빌드할 필요가 없습니다.

### 1단계 — 스택 만들기

Portainer에서 **Stacks → Add stack → Web editor**를 고른 뒤, 아래 내용을 그대로 붙여넣습니다.

```yaml
services:
  webtoon-manager:
    image: ghcr.io/murianwind/webtoon-manager:latest
    container_name: webtoon-manager
    restart: unless-stopped
    labels:
      - "com.centurylinklabs.watchtower.enable=true"
    ports:
      - "${WEB_PORT:-8000}:8000"
    environment:
      DOWNLOAD_ROOT: /webtoon_download
      WEBTOON_DOWNLOAD_HOST_PATH: ${WEBTOON_DOWNLOAD_HOST_PATH}
      ARCHIVE_ROOT: /webtoon_archive
      DATABASE_PATH: /data/webtoons.db
      COOKIE_FILE_PATH: /cookies/${COOKIE_FILE_NAME:-cookies.json}
      RCLONE_CONFIG_PATH: /rclone-config/rclone.conf
    volumes:
      - ${WEBTOON_DOWNLOAD_HOST_PATH}:/webtoon_download
      - ${WEBTOON_ARCHIVE_HOST_PATH}:/webtoon_archive
      - ${APP_DATA_HOST_PATH}:/data
      - ${COOKIE_DIR_HOST_PATH}:/cookies:ro
      - ${RCLONE_CONFIG_HOST_PATH}:/rclone-config
```

### 2단계 — 환경변수 채우기

아래로 스크롤해서 **Environment variables**에 다음을 채워 넣습니다.

| 이름 | 값 예시 | 설명 |
|---|---|---|
| `WEBTOON_DOWNLOAD_HOST_PATH` | `D:\Downloads\Webtoon\Webtoon_Download` | 실제로 웹툰이 저장될 폴더. 설정 화면에서도 이 경로(내 컴퓨터의 실제 위치)가 함께 보입니다 |
| `WEBTOON_ARCHIVE_HOST_PATH` | `D:\Downloads\Webtoon\Archive` | 아카이빙된 파일이 보관될 폴더 |
| `APP_DATA_HOST_PATH` | `D:\WebtoonManagerData` | 설정과 구독 기록을 저장할, 비어 있는 폴더 |
| `COOKIE_DIR_HOST_PATH` | `D:\WebtoonManagerData\cookies` | 네이버 로그인 쿠키 파일이 들어 있는 폴더 |
| `COOKIE_FILE_NAME` | `cookies.json` | 위 폴더 안 쿠키 파일 이름 |
| `RCLONE_CONFIG_HOST_PATH` | `D:\WebtoonManagerData\rclone` | rclone 설정 파일이 들어 있는 폴더(안 쓰실 거면 이 줄 자체를 지우세요) |
| `WEB_PORT` | `8000` | 브라우저로 접속할 포트(이미 쓰는 포트면 다른 숫자로) |

### 3단계 — 실행하고 접속하기

**Deploy the stack**을 누른 뒤, 브라우저에서 `http://<서버주소>:포트`로 접속합니다.

### 선택 사항

- **네이버 성인 웹툰**을 받으시려면, 브라우저 확장 프로그램(Cookie-Editor 등)으로 comic.naver.com에 로그인한 상태에서 쿠키를 JSON 파일로 내보내 `COOKIE_DIR_HOST_PATH` 폴더에 넣어 두세요. 성인 웹툰을 안 받으실 거면 건너뛰어도 됩니다.
- **아카이빙을 안 쓰실 거면** `WEBTOON_ARCHIVE_HOST_PATH`와 `ARCHIVE_ROOT` 두 줄(환경변수 한 줄, 볼륨 한 줄)을 지워도 됩니다. 그러면 "아카이빙" 탭에 안내 화면만 뜨고 나머지 기능에는 영향이 없습니다. rclone 원격만으로 아카이빙하실 거면 로컬 쪽은 없어도 됩니다.
- **자동 업데이트**: 위 YAML에는 Watchtower용 표시가 들어 있습니다. 이미 Watchtower를 쓰고 계시면 새 버전이 나올 때 자동으로 갱신되고, 이 도움말도 함께 최신으로 바뀝니다.

## 처음 켠 뒤 해야 할 일

"설정" 탭의 카드 순서대로 하시면 됩니다.

1. **"다운로드 폴더"**에서 네이버와 카카오페이지가 각각 어느 폴더에 받을지 확인합니다. 따로 고르지 않으면 설치할 때 정한 다운로드 폴더에 받습니다.
2. **카카오페이지**도 쓰시려면 **"카카오웹툰 관리"**에서 켜고 로그인 쿠키를 붙여넣습니다. 자세한 방법은 [카카오페이지 사용하기](#카카오페이지-사용하기)를 보세요.
3. **"실행 스케줄"**에서 새 회차를 받을 시각을 정합니다. 스케줄은 여러 개 만들 수 있고, 스케줄마다 받을 대상(네이버 / 카카오페이지 / 둘 다)을 고릅니다.
4. 알림과 리포트를 받으시려면 **"디스코드 설정"**에 웹훅 주소를 입력하고 저장합니다(완결 알림의 버튼까지 쓰시려면 봇 토큰과 채널 ID도 함께). 저장하면 그 아래에 "다운로드 리포트" 설정이 나타납니다. 디스코드 없이도 다운로드는 그대로 동작합니다.
5. **"웹툰 전체목록" 탭**에서 이미 보고 있던 작품을 찾아 **"구독"**을 누릅니다.
6. **"작가/태그 관리" 탭**에서 좋아하는 작가를 검색해 등록하거나 관심 있는 장르 태그를 추가합니다.

이렇게 한 번만 해 두시면, 그다음부터는 신작이 나와도 자동으로 구독되고 자동으로 받아집니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 웹툰 전체목록 | 네이버(그리고 켜 두면 카카오)의 연재작을 훑어보고 구독/제외를 정하는 곳. 검색, "구독중만/아직 미등록만" 필터, "신작만/휴재만/새 에피소드만" 필터가 있고, 여러 개를 골라 한 번에 "제외됨"으로 옮길 수도 있습니다 |
| 구독해제 | 한 번이라도 구독했다가 지금은 안 받는 작품 목록 |
| 제외됨 | "이건 안 볼래"라고 정한 작품 목록 |
| 수동 다운로드 | 작품을 검색해서 원하는 회차만 골라 받는 곳(네이버, 카카오페이지). 검색 결과와 분석 화면에서 바로 **구독**할 수 있고, 제목을 누르거나 **작품 페이지** 버튼으로 원본 작품 페이지를 열 수 있습니다 |
| 작가/태그 관리 | 자동 구독을 위한 관심 작가/태그를 등록하고 해제하는 곳 |
| 이력 | 다운로드 이력, 실행 이력, 아카이빙 이력을 확인하고 검색하는 곳 |
| 수동 실행 | 신작 스캔, 다운로드, 메타 동기화, 리포트 발송, 아카이빙을 지금 바로 실행하고 진행 상황을 보는 곳 |
| 아카이빙 | 보관 폴더 설정, 웹툰별·폴더별 보관 대상, 파일명 변경, 완결 자동 이동, 폴더 일괄 이동 |
| 설정 | 다운로드 폴더, 카카오 설정, 실행 스케줄, 디스코드 알림, 다운로드 리포트, 작가 자동 등록, 구독해제 관리, 백업/복원 |
| 도움말 | 지금 보고 계신 이 설명서 |

작품 카드에는 이런 표시가 붙습니다.

- **신작**: 새로 시작한 작품
- **완결**: 연재가 끝난 작품
- **휴재**: 잠시 쉬고 있는 작품
- **UP**: 새 회차가 올라온 작품. 이 표시는 "웹툰 전체목록" 탭을 열어서 전체 목록을 훑을 때 갱신되므로, 특정 작품의 UP이 안 보이면 그 탭을 한 번 열어 보세요
- **네이버 / 카카오**: 어느 플랫폼 작품인지 표시
- **구독중 / 구독해제 / 제외됨**("웹툰 전체목록"에서만): 구독해제 표시는 실제로 구독했던 작품에만 붙습니다

## 설정 화면

설정 탭의 카드는 이 순서로 있습니다.

1. **다운로드 폴더**
2. **카카오웹툰 관리**: 켜기/끄기와 로그인 쿠키
3. **실행 스케줄**
4. **디스코드 설정**: 웹훅, 봇 토큰, 채널
5. **다운로드 리포트**: 디스코드 웹훅을 저장해야 나타납니다(보낼 곳이 있어야 의미가 있기 때문입니다)
6. **작가 자동 등록**, **구독해제 관리**, **백업/복원**

"다운로드 리포트"를 빼면 모든 카드가 항상 보입니다. 웹훅이 없을 때는 "카카오웹툰 관리"에 "알림은 받을 수 없고 다운로드는 그대로 동작한다"는 안내가 함께 나옵니다. "다운로드 리포트"가 안 보이는 것은 화면에서 숨긴 것일 뿐이고, 저장해 둔 리포트 설정은 그대로입니다.

**다운로드 폴더**
- 네이버와 카카오페이지를 **서로 다른 폴더**에 받을 수 있습니다. 폴더를 직접 입력하지 않고, 설치할 때 정한 다운로드 폴더 **안에서 고르거나 새로 만듭니다**. 고르지 않으면 네이버는 다운로드 폴더 그대로, 카카오페이지는 네이버와 같은 폴더를 씁니다.
- 폴더를 바꿔도 **이미 받은 파일은 옮겨지지 않습니다.** 필요하면 직접 옮겨 주세요.
- 작품마다 그 폴더 안에 작품 제목으로 된 폴더가 만들어집니다.

**실행 스케줄**
- 새 회차 받기, 신작 스캔, 아카이빙을 몇 분마다 또는 정한 시각에 실행하도록 정합니다. 다운로드 스케줄은 여러 개 만들 수 있습니다(예: 네이버는 하루 한 번, 카카오페이지는 4시간마다).
- 다운로드와 아카이빙을 둘 다 "특정 시각"으로 정하면, 아카이빙은 다운로드보다 최소 10분 뒤로만 정할 수 있습니다.
- 다운로드 리포트를 언제 보낼지는 "다운로드 리포트" 카드에서 따로 정합니다.

## 카카오페이지 사용하기

### 켜기와 로그인

카카오페이지 작품을 받으려면 로그인이 필요합니다. "설정 > 카카오웹툰 관리"에서 **"카카오웹툰 관리하기"**를 켜고 로그인 쿠키를 붙여넣습니다.

1. 크롬에서 page.kakao.com에 로그인합니다.
2. Cookie-Editor 확장에서 **Export → JSON**으로 복사합니다.
3. 쿠키 입력칸에 그대로 붙여넣고 저장한 뒤, **"로그인 확인"**으로 실제로 로그인이 되는지 확인합니다.

쿠키는 보통 약 30일 유지됩니다. **로그인이 풀리거나 만료가 5일 안으로 다가오면 디스코드로 알려 드립니다**(같은 알림은 하루 한 번). 쿠키는 암호화해서 저장하고 백업에는 포함되지 않으니, 백업을 복원한 뒤에는 다시 붙여넣어야 합니다. 성인 작품도 이 계정으로 받아집니다.

"카카오웹툰 관리하기"를 꺼도 구독과 제외 기록은 지워지지 않고, 다시 켜면 그대로 돌아옵니다.

### 구독과 목록

- 전체목록에는 **요일 연재 중인 웹툰**이 나옵니다(웹소설, 책, 완결작은 없습니다). 목록은 프로그램을 시작할 때와 3시간마다 자동으로 갱신됩니다.
- **완결작을 받고 싶으면** "수동 다운로드"에서 카카오페이지를 고르고 제목, 작품 번호, 또는 주소(`page.kakao.com/content/…`)로 찾으세요. 검색 결과와 분석 화면에 **"구독"** 버튼이 있고, 구독하면 전체목록에 나타나 자동 다운로드 대상이 됩니다.
- 카카오페이지의 **"구독"은 자동 다운로드 대상이 된다는 뜻**입니다(네이버와 같습니다). 웹툰 뷰어 서버 설정과는 상관없습니다.
- 작품 제목을 누르면 카카오페이지의 작품 페이지가 열립니다.
- 예전에 카카오웹툰 시절의 구독/제외 기록이 있었다면, 카카오페이지 목록을 처음 받은 직후 **한 번 자동으로 옮겨집니다**. 제목이 정확히 하나만 일치하는 작품만 옮겨지고, 옮기지 못한 "제외됨" 기록은 지워집니다(지금도 연재 중인 작품이면 전체목록에 다시 나타납니다).

### 무엇을 받는지

작품 폴더에 있는 파일과 **"받은 회차 기록"**을 보고 정합니다(자동/수동 다운로드 모두 같은 규칙입니다). 받은 회차 기록은 이 앱이 받았거나 폴더에서 확인한 회차 번호를 작품마다 기억해 두는 것으로, **아카이빙으로 파일이 보관 폴더에 옮겨져도 남습니다.**

1. **폴더가 없거나 비어 있으면**: 프롤로그를 포함해 처음부터 전부 받습니다. 폴더를 일부러 비우면 기록도 버리고 처음부터 다시 받습니다.
2. **파일이 있으면**: 기록과 폴더를 합쳐서 **빠진 회차**를 받습니다. 가장 앞의 받은 회차보다 앞쪽 회차는 받지 않습니다.
3. **받은 회차 기록이 아직 없는 작품**(이 기능이 생기기 전부터 받던 작품)은 프로그램을 시작할 때 폴더의 파일과 아카이빙 이력으로 기록을 한 번 만듭니다. 결과는 "설정 > 이력 > 실행 이력"에 작품마다 한 줄씩 남습니다. 폴더 안에서 중간에 빠진 회차는 기록하지 않아서 받게 됩니다.
4. 예전 다른 도구가 남긴 폴더처럼 **파일이 딱 하나뿐이고 아카이빙 이력도 없으면** 그 파일을 "여기까지 받았다"는 표시로 보고 그 다음 회차부터 받습니다(이 경우의 기록은 첫 다운로드 때 만들어집니다).

**무료(또는 대여 중)인 회차는 앞에 잠긴 회차가 있어도 올라오는 대로 바로 받습니다.** 잠긴 회차는 번호순으로 기다렸다가, 기다무가 있으면 **가장 앞의 잠긴 회차부터 하나씩** 열어서 받습니다. 예를 들어 317~363화가 기다무 구간이고 364~447화는 이미 받았는데 448화가 새로 무료가 되었다면, 다음 실행에서 448화를 바로 받고 317화를 기다무로 받습니다. 그다음 실행부터는 충전될 때마다 318, 319화… 순서로 받습니다.

받기에 실패한 회차는 파일도 기록도 남지 않아서, 아카이빙이 지나간 뒤에도 다음 실행에서 다시 받습니다. 회차 번호는 사이트의 순번이라서 "N화"의 N과 다를 수 있습니다(프롤로그와 예고편도 번호를 차지합니다).

파일은 `0384_384화 복국 (2).zip`처럼 **번호 4자리와 회차 제목**으로 저장됩니다. 예전에 다른 도구로 받은 파일(`0384_384화 복국 (2)#48.zip`처럼 뒤에 숫자가 붙은 것)도 같은 회차로 인식합니다. 이미지가 하나라도 안 받아지면 그 회차는 남기지 않고 다음 실행에서 다시 시도합니다.

### 자동 다운로드

- "설정 > 실행 스케줄 > 다운로드"에서 스케줄을 만들고 **받을 대상에 카카오페이지**(또는 둘 다)를 고릅니다. "수동 실행" 탭의 "다운로드 실행"에서도 대상을 고를 수 있습니다.
- **구독 중인 작품**이 대상이고, 로그인이 풀려 있으면 받지 않고 디스코드로 알려 드립니다.
- 한 작품에서 받을 회차가 많으면 네이버와 같은 설정(작품당 한 번에 받는 개수, 쉬는 시간)에 따라 **일정 개수를 받고 잠시 쉬었다가 같은 실행 안에서 이어서 끝까지 받습니다.** 이어 받는 동안은 그 실행이 길어지고, 같은 시간에 카카오 수동 다운로드를 하면 "다른 다운로드 실행 중"으로 막힐 수 있습니다.
- 완결된 작품이 **받을 회차를 다 받으면** 완결 알림을 보냅니다. 완결인데 잠긴 회차가 남아 있으면 아직 알리지 않습니다.

### 수동 다운로드

작품을 검색하거나 번호/주소를 넣으면 회차 표가 나옵니다.

- **상태**: 무료 / 보유(대여 중) / 잠금 / 기다무. 이미 받은 회차는 "이미받음", 시작 지점보다 앞이라 받지 않을 회차는 "이전 회차"로 표시됩니다. **아카이빙으로 보관 폴더에 옮겨진 회차도 "이미받음"으로 보이고, "보관 폴더로 옮김"이 함께 붙어서** 폴더에 있는 것과 구분됩니다. 요약에도 "이미 받음 N개(그중 보관 폴더로 옮긴 K개)"로 나오므로 아직 받지 못한 회차가 한눈에 보입니다.
- **"대여 만료" 칸**: 대여 중인 회차는 만료 시각이, 잠긴 "N일 후 무료" 회차는 무료가 되는 날짜(예: `2026-10-07 무료`)가 나옵니다.
- **이미 받은 회차도 골라서 다시 받을 수 있습니다.** 다시 받기가 끝까지 성공한 뒤에만 예전 파일을 바꿔서, 실패하면 원래 파일이 그대로 남습니다.
- **"전체선택"**은 받을 수 있는 회차를 모두, **"미보유만 선택"**은 이미 받은 회차를 뺀 나머지만 고릅니다(받은 회차가 없으면 두 버튼이 같아서 "미보유만 선택"은 숨겨집니다).
- 화면 위쪽에 **대여권 몇 장, 기다무 대여권(작품마다 3시간/1일/3일 등 충전 주기, 지금 사용 가능 또는 사용 중 + 남은 시간)**이 표시됩니다.
- 표 위에 **"사이트 회차는 36개인데 31개만 가져왔습니다"** 같은 경고가 나오면, 사이트보다 표가 짧다는 뜻이니 빠진 회차가 있을 수 있습니다.

### 기다무와 연재무료

- **기다무 대여권**이 있는 작품에서는 잠긴 회차를 기다무로 열 수 있습니다. 자동 다운로드는 받을 수 있는 회차를 다 받은 뒤 **첫 잠긴 회차 하나**를 기다무로 열어서 받습니다(충전될 때마다 한 장씩 쓰므로, 3시간 기다무라면 4시간마다 받도록 스케줄을 정해 두면 충전을 놓치지 않습니다). 수동 다운로드에서는 기다무 한 장을 쓴다는 확인 창이 뜨고, 한 장이라 고른 것 중 번호가 가장 앞선 회차 하나만 열립니다.
- **연재무료 작품**(기다무가 없는 작품)은 기다무 항목 자체가 안 나옵니다. "N일 후 무료"로 열릴 예정인 회차는 **잠금으로 표시**되고, 날짜가 되어 무료로 바뀌면 다음 실행에서 이어서 받습니다.
- **대여권이 필요해서 더 못 받게 되면 디스코드로 알려줍니다.** 자동 다운로드가 받을 회차를 다 받았는데 다음 회차가 기다무로 열 수 없는 회차(기다무가 없는 작품, 또는 최신 회차처럼 기다무가 안 되는 회차)이면 `[작품명] 다음 회차 (N번 '부제목')부터는 대여권 충전이 필요합니다.`라는 메시지가 갑니다. 충전을 기다리면 자동으로 이어지는 경우(기다무 충전 대기, "N일 후 무료")는 알리지 않고, **같은 회차는 한 번만** 알립니다. 웹훅이 설정돼 있지 않으면 알림을 기록하지 않아서, 웹훅을 설정하면 다음 실행 때 바로 갑니다.
- **결제(캐시나 소장권 구매)는 절대 하지 않습니다.** 선물권과 일반 대여권도 프로그램이 대신 쓰지 않습니다. 카카오페이지 웹에서 직접 쓰면 그 회차가 "대여 중(보유)"으로 나타나서 이용권 없이 받을 수 있고, 자동 다운로드도 대여 기간 안에는 그대로 받습니다. 자동 다운로드도 앞에 잠긴 회차가 있어도 대여 중인 회차는 대여 기간 안에 받아 둡니다.
- **기다무로 연 회차를 받지 못하면** 기다무는 이미 쓴 상태입니다. 그 회차는 대여 기간(보통 3일) 동안 "보유"로 남으니, 다시 분석해서 이용권 없이 받으세요.

### 정보 파일과 표지

받은 뒤 작품 폴더에 작품 정보 파일(`info.xml`)과 표지(`cover.jpg`)를 만듭니다. 정보 파일은 받을 때마다 최신으로 다시 쓰고, 표지는 없을 때만 받습니다. 연령 등급은 "15세 이용가", "18세 이용가", 그 외는 "전체이용가"로 적습니다. 예전 카카오웹툰에서 받은 표지를 카카오페이지 표지로 바꾸려면 "수동 실행"의 **메타 동기화**를 실행하세요.

### 알아 두세요

- 회차 목록에 "동영상 트레일러" 같은 **동영상**이 있거나 제목에 **"체험판"**이 들어간 회차가 있으면 받지 않고 목록에서 빼고, 뒤 회차의 번호를 당깁니다. 이미지로 된 프롤로그와 예고편은 그대로 받습니다.
- 폴더 이름에 쓸 수 없는 문자(콜론 `:` 등)는 네이버와 카카오페이지가 다르게 바꿉니다(네이버는 전각 콜론 `：`, 카카오페이지는 밑줄 `_`). 웹툰 뷰어 바로가기와 아카이빙은 이 차이를 알아서 반영합니다.
- 받은 파일을 저장하는 것은 카카오 이용약관이 허용하는 범위를 넘을 수 있어서 계정이 제한될 가능성이 있습니다. **개인 보관용으로만** 쓰세요.

## 아카이빙 사용하기

아카이빙은 다운로드 폴더에 쌓이는 파일을 별도 **보관 폴더**로 자동 정리하는 기능입니다. "아카이빙" 탭에서 설정합니다.

### 대상 정하기

대상은 두 가지로 등록합니다. 등록할 때 파일명 변경 방식도 바로 고를 수 있습니다.

- **웹툰으로 등록**: 구독 중인 웹툰(네이버, 카카오페이지)을 다운로드 폴더 기준으로 옮깁니다.
- **폴더로 등록**: 이 프로그램이 받지 않은 임의의 폴더(다른 도구로 받은 웹툰 등)를 원본 경로만 지정해서 옮깁니다.

### 옮기는 방식

- 정한 주기마다 **마지막 회차 파일은 남기고** 나머지를 보관 폴더로 옮깁니다. 마지막 파일을 남기는 이유는, 다음 회차를 이어서 받을 때 "몇 화까지 받았는지" 확인하는 표시로 쓰기 때문입니다. 카카오페이지 작품은 받은 회차를 따로 기억하므로(받은 회차 기록) 파일이 옮겨져도 빠진 회차가 어디인지 알 수 있습니다. 정보 파일(`info.xml`)은 복사해서 항상 최신으로 덮어쓰고, 표지는 보관 폴더에 없을 때만 복사합니다.
- 여러 대상이 **같은 보관 폴더**를 지정하면 대상별 하위 폴더로 자동으로 나뉘고, 하나만 쓰면 그 폴더 바로 아래에 쌓입니다.
- 이미 파일이 있는 폴더도 지정할 수 있습니다. 다만 "이미 파일이 있습니다"라는 경고가 뜨고 "그래도 선택"을 눌러야 진행됩니다.
- **같은 이름의 파일이 이미 있을 때**(건너뛰기 / 덮어쓰기 / 이름 바꾸기)는 "아카이빙 공통 설정"에서 하나로 정하고, 모든 이동에 똑같이 적용됩니다.

### 완결된 작품 정리

- 완결된 작품을 **구독해제하면**(설정에서 이 기능을 켜 둔 경우) 이동 대기열에 들어가고, 다음 아카이빙 스케줄이 돌 때 마지막 회차까지 전부 옮겨집니다(구독해제하는 즉시 옮겨지는 것은 아닙니다). 스케줄이 꺼져 있으면 "수동 실행"에서 직접 처리하세요. 대상으로 지정하지 않은 작품은 "완결 자동이동 설정"에서 정한 기본 보관 폴더로 갑니다.
- 카카오페이지 작품도 똑같이 적용됩니다. 디스코드 완결 알림의 "구독해제" 버튼을 눌러도 같은 대기열에 들어갑니다.
- **"수동 실행"에서 "완결 처리로 이동"**을 켜면 지정한 대상을 바로 전부 옮길 수 있습니다. 연재 중인 작품에도 쓸 수 있어서, 실수로 누르지 않도록 한 번 더 확인합니다.
- 완결 처리로 옮길 때 카카오페이지 작품이면 **표지를 카카오페이지 공식 표지로 새로 받아서** 교체합니다. 작품 정보 파일에 카카오페이지 주소가 적혀 있을 때만 하고, 예전 카카오웹툰 주소가 적힌 폴더는 건드리지 않습니다(메타 동기화로 정보 파일을 새로 쓰면 카카오페이지 주소로 바뀝니다). 표지를 못 받아도 이동은 그대로 진행됩니다.

### 파일명 바꾸기

"아카이빙 공통 설정"에서 파일명 변경 방식을 여러 개 만들어 두고 대상마다 고를 수 있습니다. 고르지 않으면 기본 방식을 쓰고, 그것도 비워 두면 원래 파일명 그대로 옮깁니다.

- 쓸 수 있는 항목: `{title}`(웹툰 제목), `{episode_no}`(회차 번호), `{subtitle}`(회차 제목), `{page_count}`(페이지 수), `{author}`(작가)
- 예: `{title} {episode_no}화 - {subtitle}#{page_count}`
- `{author}`는 **글 작가**입니다(원작자나 그림 작가가 아닙니다).
- 네이버 방식(`{번호} {제목} {회차 제목}`)과 카카오 방식(`{번호}_{회차 제목}`) 파일을 둘 다 인식합니다. 둘 다 아니면 원래 파일명 그대로 옮깁니다. 정보 파일과 표지에는 적용되지 않습니다.
- 회차 번호는 파일 이름에 적힌 번호를 그대로 씁니다. 네이버 파일은 이 번호가 실제 회차 번호가 아니라 "끊김 없는 순번"이라서, 회차가 건너뛴 적 있는 작품은 그 뒤부터 실제 번호와 어긋날 수 있습니다.

### 폴더 일괄 이동

아카이빙 대상과는 별개로, 폴더 안의 **파일들**을 원하는 곳으로 **한 번만** 옮기고 싶을 때 씁니다(예: 예전에 쌓아 둔 백업 정리, 구독하지 않는 완결작을 보관 폴더로 이동). 로컬 폴더와 rclone 원격을 자유롭게 섞을 수 있고, 파일명 변경 방식과 "카카오 표지 새로 받기"를 고를 수 있습니다. 끝나고 원본 쪽에 파일이 하나도 안 남으면 그 폴더도 정리합니다. "지금 이동"을 누르면 진행 상황이 실시간으로 표시됩니다.

### rclone 원격(원드라이브 등)을 보관 폴더로 쓰고 싶다면

Windows에서 rclone으로 마운트한 드라이브는 Docker Desktop이 인식하지 못합니다. 대신 이 프로그램이 컨테이너 안에서 rclone을 직접 실행해서 원격에 올립니다. 컨테이너에는 [wiserain/rclone](https://github.com/wiserain/rclone)(원드라이브 안정성이 개선된 버전)의 최신 버전이 자동으로 설치됩니다.

1. Windows에서 미리 rclone 설정을 마쳐서 설정 파일(`rclone.conf`)을 만들어 둡니다(`rclone config` 명령, 보통 `%USERPROFILE%\.config\rclone\rclone.conf`).
2. 그 파일이 있는 **폴더**를 환경변수 `RCLONE_CONFIG_HOST_PATH`로 지정합니다.
3. "아카이빙" 탭의 폴더 선택 화면에 **"rclone 원격"** 버튼이 나타나면 연결된 것입니다. 로컬 폴더와 똑같이 찾아보기와 새 폴더 만들기를 쓸 수 있습니다.

## 알려진 한계와 하지 않는 것

- **카카오페이지의 받은 회차 기록이 없는 작품**은, 아카이빙으로 마지막 파일만 남은 뒤에는 앞쪽의 빠진 회차를 알 수 없습니다. 이 기능이 생기기 전에 이미 아카이빙이 지나가서 폴더에 파일이 하나만 남았고 아카이빙 이력도 지워졌다면, 그 앞 회차는 "이전 회차"로 남고 자동으로 받지 않습니다(수동 다운로드로 받을 수 있습니다). 프로그램을 시작할 때 만든 기록 결과는 "설정 > 이력 > 실행 이력"에서 작품마다 확인하세요.
- **하지 않는 것**: 결제, 선물권과 일반 대여권의 자동 사용(기다무만 씁니다), 카카오페이지의 동영상·체험판 회차 다운로드, 카카오페이지의 태그/키워드로 신작을 찾는 기능(작가로만 찾습니다).
- 플랫폼의 요일별 목록에 없는 완결·장기휴재 작품은 구독한 적이 없으면 전체목록에서 찾지 못할 수 있습니다.

## 자주 묻는 질문

<details markdown="1">
<summary>Q. 네이버 성인 웹툰이 하나도 안 받아져요.</summary>

쿠키 파일이 제대로 연결되어 있는지, 그리고 로그인이 아직 유효한지 확인해 주세요. 쿠키가 만료되면 디스코드로 알림이 갑니다(웹훅을 설정해 두셨다면).
</details>

<details markdown="1">
<summary>Q. 카카오페이지 작품이 하나도 안 받아져요.</summary>

"설정 > 카카오웹툰 관리"에서 로그인 쿠키를 저장하고 **"로그인 확인"**을 눌러 보세요. 로그인이 풀려 있으면 받지 않고 디스코드로 알립니다. 그리고 "실행 스케줄 > 다운로드"의 받을 대상에 **카카오페이지**가 들어 있는지, 받으려는 작품이 **구독 중**인지도 확인해 주세요.
</details>

<details markdown="1">
<summary>Q. 카카오페이지 작품의 회차가 잠겨 있어서 안 받아져요.</summary>

작품마다 사정이 다릅니다. **기다무가 있는 작품**은 충전될 때마다 한 회차씩 열립니다. **연재무료 작품**은 "N일 후 무료"로 표시된 회차가 그 날짜가 되어야 열리고, 그전에는 잠금으로 표시되며 날짜가 되면 다음 실행에서 이어서 받습니다. 자세한 내용은 [카카오페이지 사용하기](#카카오페이지-사용하기)를 보세요.
</details>

<details markdown="1">
<summary>Q. 카카오페이지 작품의 파일을 지웠는데 다시 받지 않아요.</summary>

받은 회차 기록에 남아 있는 회차는 파일이 없어도 "받은 회차"로 봅니다(아카이빙으로 옮겨진 회차와 구별할 수 없기 때문입니다). 다시 받으려면 **수동 다운로드**에서 그 회차를 골라 받거나, **작품 폴더를 통째로 비우세요.** 폴더를 비우면 기록도 버리고 처음부터 다시 받습니다.
</details>

<details markdown="1">
<summary>Q. 같은 내용의 리포트가 계속 와요.</summary>

받은 회차와 실패한 회차, 미등록 작품의 새 에피소드는 **같은 회차를 한 번만** 보고합니다. 보낼 새 내용이 없으면 메시지 자체를 보내지 않습니다. 단, 업데이트한 직후의 첫 리포트에는 그동안의 기록이 한 번 더 나올 수 있습니다. "테스트 발송"은 오늘 기록을 전부 보여 주고 기록은 남기지 않으니, 테스트 뒤에 오는 정상 리포트에는 같은 내용이 또 나오는 게 맞습니다.
</details>

<details markdown="1">
<summary>Q. 구독해제나 제외됨 목록의 작품에 태그나 신작 표시가 안 보여요.</summary>

정기적으로(신작 스캔이 돌 때) 자동으로 채워지지만, 방금 구독해제하거나 제외하셨다면 아직 정보를 못 받아온 상태일 수 있습니다. "작가/태그 관리" 탭의 **"지금 전체 재동기화"**를 누르면 바로 채워집니다. 카카오페이지 작품의 작가 정보도 이때 함께 채워집니다.
</details>

<details markdown="1">
<summary>Q. 신작 자동 구독을 잠깐 멈추고 싶어요.</summary>

"작가/태그 관리" 탭에서 해당 작가나 태그를 "제외" 버튼으로 꺼 두시면 됩니다. 이미 구독 중인 작품은 그대로 유지되고, 그 작가/태그의 **새 작품만** 더 이상 자동으로 구독되지 않습니다.
</details>

<details markdown="1">
<summary>Q. 백업은 어떻게 하나요? 무엇이 들어가고 무엇이 빠지나요?</summary>

설정 탭의 "백업/복원"에서 **"백업 다운로드"**를 누르면 파일 하나로 받을 수 있고, 나중에 **"복원 파일 선택"**으로 되돌릴 수 있습니다.

- **들어가는 것**: 구독·구독해제·제외 목록(네이버, 카카오페이지), 관심 작가/태그, 다운로드·아카이빙 이력, 아카이빙 대상과 파일명 변경 방식, 실행 스케줄, 다운로드 폴더 설정을 포함한 각종 설정, 카카오페이지의 작가 정보·완결 상태·받은 회차 기록
- **빠지는 것**: 디스코드 웹훅·봇 토큰, 카카오페이지·네이버 로그인 쿠키(비밀 정보라서), 그리고 **다운로드한 파일과 보관 폴더의 파일**(백업은 목록과 설정만 담습니다)
- 복원하면 현재 데이터가 백업 내용으로 **통째로 바뀝니다**(확인 창이 한 번 뜹니다). 다만 **지금 설정된 디스코드 웹훅/봇 토큰과 카카오페이지 로그인 정보는 그대로 유지**됩니다.
- 복원한 스케줄은 **바로 적용**되고, 카카오페이지가 켜져 있으면 전체목록도 새로 받아 옵니다.
</details>

<details markdown="1">
<summary>Q. 완전히 새로운 컨테이너를 만들고 복원하려면 어떻게 하나요?</summary>

1. 설치할 때와 똑같이 새 컨테이너를 만들되, **다운로드 폴더와 보관 폴더(`WEBTOON_DOWNLOAD_HOST_PATH`, `WEBTOON_ARCHIVE_HOST_PATH`)는 예전에 쓰던 폴더를 그대로 연결**합니다. 이 폴더에 이미 받아 둔 파일이 있어야 이어서 받습니다.
2. 접속해서 설정 탭의 "백업/복원"에서 백업 파일을 복원합니다.
3. 복원이 끝나면 화면에 **"확인해 주세요"와 "다시 입력해 주세요"** 안내가 나옵니다. 그대로 따라 하세요.
    - **다시 입력할 것**: 디스코드 웹훅(필요하면 봇 토큰과 채널 ID), 카카오페이지 로그인 쿠키, 네이버 성인 웹툰을 받는다면 쿠키 파일(`COOKIE_DIR_HOST_PATH` 폴더)
    - **확인할 것**: 구독 중인 작품의 폴더가 없다는 경고, rclone 설정 파일이나 보관 폴더가 연결돼 있지 않다는 경고, 예전 다운로드 폴더 경로가 이 환경에 없어서 기본 폴더로 되돌렸다는 안내
4. **카카오페이지 작품의 폴더가 없다는 경고가 나오면 자동 다운로드 스케줄이 돌기 전에 폴더 연결부터 확인하세요.** 카카오페이지는 작품 폴더가 없으면 처음부터 전부 받습니다. 예전 파일이 있는데 폴더가 연결되지 않은 채로 스케줄이 돌면 이미 가진 회차를 다시 받게 됩니다.

백업 파일은 같은 프로그램 또는 더 새로운 버전에서만 복원할 수 있고, 더 새로운 버전에서 만든 백업을 예전 버전에 복원하려 하면 거부됩니다. 백업 파일이 아닌 파일을 올려도 거부되고 데이터는 그대로 남습니다.
</details>

<details markdown="1">
<summary>Q. 완결 작품 아카이빙은 주기를 정할 수 있나요?</summary>

네. 완결된 작품을 구독해제하면 바로 옮겨지는 것이 아니라 대기열에 들어가고, "실행 스케줄"에서 정한 아카이빙 주기가 돌 때 처리됩니다. 스케줄이 꺼져 있으면 대기열에 쌓인 채로 남으니, "수동 실행"에서 직접 돌려 주세요.
</details>

<details markdown="1">
<summary>Q. 다운로드 리포트에 웹툰 뷰어로 가는 바로가기 링크가 안 붙어요.</summary>

설정 탭에 **웹툰 뷰어 서버 주소**를 입력해 두셔야 합니다. 입력하지 않으면 링크 없이 제목만 나열됩니다(카카오페이지 작품은 카카오페이지 링크가 대신 붙습니다).
</details>

<details markdown="1">
<summary>Q. 리포트의 "목록 제외" 링크를 눌러도 아무 일도 안 일어나요.</summary>

"설정" 탭에 이 프로그램의 **외부 접속 주소**(예: `https://webtoon.example.com`)를 입력해 두셔야 링크가 만들어집니다. 입력하지 않으면 미등록 웹툰 항목에는 바로가기만 붙고 "목록 제외" 링크는 나오지 않습니다. 링크를 열면 실수를 막기 위해 확인 페이지가 한 번 뜨고, 거기서 버튼을 눌러야 실제로 제외됩니다.
</details>

<details markdown="1">
<summary>Q. 리포트의 "웹툰 전체목록 중 새 에피소드"는 무엇이고, 끌 수 있나요?</summary>

전체목록에 있지만 **구독하지 않은** 작품(네이버, 카카오페이지) 중 새 회차가 올라온 것을 알려 주는 섹션입니다. 같은 회차는 처음 발견한 리포트에서 한 번만 알립니다. 구독 중인 작품은 이 앱이 직접 받아서 "받은 작품"에 나오므로 여기에는 나오지 않고, 구독해제하거나 제외한 작품도 나오지 않습니다. 구독해제나 제외됨에 있던 작품도 **"목록으로"** 되돌리면 다시 전체목록의 미구독 작품이 되어 알림 대상이 됩니다. 성인 작품(네이버 18세, 카카오페이지 19세)은 성인 인증/로그인 쿠키로 확인하므로, 쿠키가 없거나 만료되면 이 섹션에 나오지 않고 "수동 실행"의 리포트 실행 기록에 "확인하지 못했습니다"라고 남습니다. 필요 없으시면 "설정" 탭의 "다운로드 리포트"에서 "미등록 웹툰 중 새 에피소드 섹션 포함"을 끄세요.
</details>

<details markdown="1">
<summary>Q. "구독해제" 탭에 원하지 않는 웹툰이 섞여 있어요 / 실수로 완전히 사라진 웹툰이 있어요.</summary>

"설정" 탭의 **"구독해제 관리"**를 이용하세요. 구독했던 기록이 있는데 지금은 구독 중이 아닌 웹툰을 모아서 보여 주고, 원하지 않는 것을 "초기화"하면 구독 기록이 없는 상태로 돌아갑니다. 반대로 titleId만 알고 있으면 "구독해제" 상태로 직접 복구할 수도 있습니다. 이 기능은 네이버 웹툰 전용입니다.
